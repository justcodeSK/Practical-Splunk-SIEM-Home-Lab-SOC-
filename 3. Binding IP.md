# Binding IP Address
- First stop splunk
```bash
sudo ./splunk stop
```
- We need to bind the ip address so the the ipcan be accessed from any where.
- Navigate to the /opt/splunk/etc/ directory.
- Fnd ***Splunk-launch.conf***.
```bash
sudo su
nano splunk-launch.conf
```
- Now edit the splunk launch configuration file and edit the ***SPLUNK_BINDIP=0.0.0.0***, if there is no SPLUNK_BINDIP, just add one and type 0.0.0.0 as wild card address.
```
SPLUNK_HOME=/opt/splunk
SPLUNK_BINDIP=0.0.0.0
```
- ctrl+x and ctrl+o to save and exit nano editer.
- Restart the splunk
```bash
cd /opt/splunk/bin
sudo ./splunk start
ifconfig
```
- ifconfig to copy the ip address.
- As out put we can see the splunk is running as 0.0.0.0:8000 default web server, where we ca access the splunk even in our host system.
- Login to splunk by entering the ****<Ip address of ubuntu server>:8000*** on your we browser.
- Login using userid and password we cnfigured while splunk installation.

>[! TIP]
>The splunk has been installed and binded the ipaddress for all in the network to access and setup the ufw firewall rules to accept the 8000 port all tcp traffic inbound and outbound.
