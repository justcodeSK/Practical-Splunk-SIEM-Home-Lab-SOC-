# Splunk Enterprise Installation

## 1. Download Splunk

- Download the latest **Splunk Enterprise `.deb` package** for Linux from the official Splunk website and transfer it to the Ubuntu server.
or 
Go to ***https://www.splunk.com/*** and Naavigate to ***Platforms*** tab and Click on ***Enterprise*** and Splunk Platform -> Splunk Enterprise and Click on free trials button, fill the forms ***(use a Temp mail and Temp phone no.)***, then when 64 bit splunk download page enters below downlods button there is a wget code just copy the code, i have attached that code below.
```
wget -O splunk-10.4.1-5a009d941268-linux-amd64.deb "https://download.splunk.com/products/splunk/releases/10.4.1/linux/splunk-10.4.1-5a009d941268-linux-amd64.deb"
```
- After ubuntu server is ready to use Create a folder on /home/Downloads path.
- Copy paste ths wget code in it and the Splunk Enterprise version package is downloaded to that location.
- We list the file details
```
abc@abcserver:/home$ ls
Downloads  ubuntu
abc@abcserver:/home$ cd Downloads
abc@abcserver:/home/Downloads$ ls
splunk-10.4.1-5a009d941268-linux-amd64.deb
```
> [!TIP]
> Splunk Installation Package Successfully Downloaded.
---
## 2. Install the Package
- After Downloading the Package we have to extract the file.
```bash
cd ~/Downloads
sudo dpkg -i splunk-10.4.1-5a009d941268-linux-amd64.deb
```
> [!TIP]
> Splunk Package has been Extracted.
