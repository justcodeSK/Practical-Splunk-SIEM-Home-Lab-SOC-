## 2. Install the Package
- After Downloading the Package we have to extract the file.
```bash
cd ~/Downloads
sudo dpkg -i splunk-10.4.1-5a009d941268-linux-amd64.deb
./splunk start
```

> [!CAUTION]
> The splunk dident start according to this command.
> Found the reason, Splunk permissions are not set.

> [!TIP]
> To setup First i properly used debin package management and used ***chown*** to make perissions right.
  
## Debian Software Package Management(dpkg) in Linux
- Debian Software Package Management(dpkg) is the low-level package management system used in Debian-based Linux operating systems. It installs, removes, configures, and manages software packages in the .deb format without handling dependencies automatically.

## chown Command in Linux
- The chown command in Linux allows modifying the ownership of files or directories. It can assign a new user, group, or both, either individually or simultaneously. only root or privileged user (via sudo) can change ownership.

```bash
cd ~/Downloads
sudo dpkg -i splunk-*.deb
```
- ```*``` will allow to fill the remaining fille name.
- Now we need to set up splunk permissions.
```bash
sudo chown -R splunk:splunk /opt/splunk
```
- ***chmod*** Change ownership, ***-R***, ***splunk:splunk*** give ownership to ***splunk*** user and ***splunk*** group in the ***/opt/splunk*** folder.
- Now start Splunk Damon, Splunk Damon is a background service to run splunk in background.
```bash
sudo /opt/splunk/bin/splunk enable boot-start -user splunk --accept-license --answer-yes
```
- Start splunk Damon from binary folder ***/opt/splunk/bin/splunk*** enable boot and start splunk with the user ***enable boot-start -user splunk*** and automatically acccept license and answer to all as yes ***--accept-license --answer -yes***.
- We configure user id and password.
```bash
sudo ./splunk start
```
